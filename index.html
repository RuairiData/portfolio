Project 7 — Client Pipeline & Task Monitoring (Power BI)

Power BI • DAX • semantic model • operational KPIs

Why it’s relevant for Power BI roles

This is an operational pipeline dashboard: it tracks clients in-flight, assets in pipeline vs expected assets, task status (active/pending), and ageing (e.g., tasks by age band) with slicers for owner/consultant and agent firm. It demonstrates end-to-end BI thinking: clear KPI definitions, drillable breakdowns, and a model that supports fast, reliable filtering.

Data privacy note: before sharing, I anonymise personally identifying fields (owners/consultants/firms) by mapping them to synthetic labels (e.g., Owner A12, Firm K07) so no real identifiers appear in visuals.
